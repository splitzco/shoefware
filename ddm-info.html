Visualization

Click anything. Know everything.

The interactive diagram organizes every application by patient-care phase — Pre-Registration through Post-Discharge — with a separate grid for infrastructure and support systems. Click any application, contract, project, or hardware profile to open a full detail sidebar.

  • Drill into scrollable field lists with working back-navigation
  • Data flows shown as a searchable, filterable list connecting source and target applications
  • Retired applications hidden by default, revealable with one toggle — search surfaces them automatically if a match is retired
  • Collapse to search-only mode for CIOs who prefer typing over browsing
Search

One search bar. Every category, simultaneously.

A single query covers applications, data flows, contracts, projects, entities, hardware profiles, phases, data fields, project documents, and departments — each rendering as its own labeled results category.

Results are fully cross-referenced: a matched contract or project lights up every application it touches on the diagram, not just what's directly tagged.

Field Tracing

The blast radius answer — instantly.

Trace any patient data field (SSN, MRN, Guarantor, Date of Birth, etc.) to every application and data flow that touches it. This is the definitive answer to: "what's exposed if this is compromised?"

Core fields aren't a guess at what matters — they're grounded in the identifier categories HIPAA's Safe Harbor de-identification method defines (45 CFR §164.514(b)(2)), reviewed against what your systems actually capture.

  • Core Categories — a HIPAA Safe Harbor–grounded bundle (45 CFR §164.514(b)(2)) of identifier fields, inherited by an application in one click instead of tagging dozens of fields individually
  • Per-application exceptions for the rare case a Core app is missing one field — accuracy is never sacrificed for speed
  • Every result honestly distinguishes "directly tagged" from "inherited via Core", with the legal citation shown inline
Structure

Everything your IT organization tracks, in one repository.

DDM™ is not just a diagram — it's a full asset and relationship registry for the entire organization.

  • Entities — track which health system(s) own an application, critical during mergers and acquisitions
  • Departments — sub-units of an entity (e.g., "Orthopedics" under Riverwell); scoped per-entity so a widely-used app doesn't produce an unmanageable wall of checkboxes
  • Contracts — vendor tracking with typed classifications (BAA, License, Maintenance & Support, Implementation/Consulting, MSA, and more), PDF attachment, and links to every application, project, or hardware profile each contract covers
  • Projects — full lifecycle tracking: type, PM, budget vs. actual with live variance, status, linked applications and contracts, plus a Documents & Links section (Epic Userweb articles, specs) labeled Internal or External
  • Hardware Profiles — tracked alongside applications with the same contract and project linkage
  • Attributes — flexible per-application custom fields (text, number, boolean, date) for compliance flags, vendor details, or anything else — organized into categories

AI Powered

Ask DDM anything, in plain English.

DDM Plus adds a Claude-powered AI connector (MCP) that lets any authorized user query the entire platform by voice or text — no training required. Five purpose-built tools cover every common investigation:

  • Search DDM — keyword search across the entire platform

  • List All Projects — cross-project comparison, budget analysis, and charting
  • Find Contracts / Projects / Hardware by Date Range — expiration and renewal tracking

DDM Plus is licensed per the customer's existing Claude subscription — the AI cost never lands on shoëfware.
