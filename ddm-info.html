Every application knows where your patient data goes.
Do you?

The Doyen Data Model™ is a vast healthcare IT repository — cataloging patient data elements, application inventories, vendor information, workflows, project plans, contact records, and every interface between them. All of it searchable, in seconds.

A simplified view of the model: applications organized across the patient journey, with patient-data systems kept visually distinct from support systems — and every flow between them tracked.

The problem

Nobody can answer "where does this live?" quickly.

In a typical health system, patient data doesn't live in one place — it's scattered across registration, lab, pharmacy, billing, and dozens of interfaces between them. When a CIO or analyst needs to know which applications touch a specific piece of data, the honest answer is usually: a spreadsheet, a few tribal-knowledge conversations, and a guess.

The model

One inventory. Every application, every phase.

DDM organizes every application by where it sits in the patient journey — pre-registration, arrival, during stay, discharge, and post-discharge — and marks clearly which ones handle patient data and which are support systems.

Every connection between applications is tracked as a data flow, and any flow that crosses from a patient-data system into a support system is flagged automatically — the exact moment protected data leaves its natural boundary.

The payoff

Search for a field. Get every place it lives.

Type "Medical Record Number" and see every application and every interface that captures it — not a guess, a query. DDM™ turns "where does this live?" from a multi-day investigation into a search box.

DDM™ — The Doyen Data Model™ is a shoëfware,inc. product, self-hosted within your own infrastructure.
